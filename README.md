# Университет жатақханасында техникалық ақауларға өтінімдерді қабылдау және жөндеу процесін автоматтандыру

## Шешілетін проблема
Жатақханада ақау (электр, су, жылу) туралы студент коменданттың есігіне
барып ауызша айтады, өтінім қағазға жазылады немесе жоғалады, ал жөндеу
апталап созылады. Студент өтінімінің тағдырын білмейді, басшылық жұмыстың
нақты жағдайын көрмейді.

## Процеске қатысушылар (Pool және Lane)
**Pool:** Жатақханада техникалық ақауларды жою процесі

- **Lane 1:** Студент (Тұрғын)
- **Lane 2:** Комендант
- **Lane 3:** Техник (электрик, слесарь, ұста)
- **Lane 4:** Ақпараттық жүйе (TO-BE моделі үшін)
